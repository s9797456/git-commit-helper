0.1.0

  • First public release.
  • Toolbar action in the commit message box that turns the checked files into a subject line plus an itemized body, with a replace / append / cancel preview.
  • Local, deterministic grouping with an optional LLM rewriting step (OpenAI-compatible, Anthropic, Gemini) and automatic fallback to the local result.
  • Output format and prompt templates, with presets.
  • .gitmessage / git config commit.template used as the output skeleton.
  • {issue} injection from the branch name or recent commits.
  • Changelog and PR description generation (copy only).
  • Chinese and English output.
