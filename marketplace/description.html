Commit Helper

Turns the changes you have checked in the commit panel into a ready-to-commit message: a subject line plus an itemized body. Grouping of files and modules is done locally and deterministically; an optional LLM (OpenAI-compatible, Anthropic or Gemini) only takes care of the wording. If the model is unreachable, the plugin writes the local grouping result instead of failing.

Nothing is generated until you click, and nothing is ever committed for you: the plugin only proposes text in the commit message box, where you can edit it as usual.

Features

  • Toolbar action in the commit message box — click Organize Commit Message and review the proposal in the preview dialog (replace, append or cancel).
  • Hybrid generation — file/module grouping is computed locally; the LLM only rewrites the wording.
  • Editable templates — output format template and prompt template, both with presets (Conventional Commits style by default).
  • Repository commit template — an existing .gitmessage / git config commit.template is used as the output skeleton, and its comment lines are preserved.
  • Issue key injection — {issue} is extracted from the branch name or recent commit subjects. No Jira/GitHub API calls.
  • Changelog and PR description — generated in a preview window for copying; no files are written and no git commands are executed.
  • Multi-vendor LLM support — OpenAI-compatible endpoints, Anthropic and Gemini, each configurable, with a local only mode.
  • Chinese and English output — switchable per generation.

Getting started

  1. Open Settings | Tools | Commit Helper and pick a provider, or stay on Local only (no account needed).
  2. Check the files you want in the commit tool window, click the commit message box, then click Organize Commit Message in its toolbar.
  3. Review the proposal, then replace or append.

Large changesets are sampled and noisy files (lock files, build output, minified bundles, binaries) are summarised instead of being sent in full. Unversioned files are read from disk; files larger than 1 MB are skipped.

Privacy

Only the diff of the files you explicitly checked is sent to the provider you configured. API keys are stored in the IDE credential store (Password Safe), never in the project. All network access is disabled in Local only mode.

Requirements

  • IntelliJ Platform 2024.1 or newer (IntelliJ IDEA, and any IDE shipping the platform and Git support).
  • Git4Idea (bundled with IntelliJ IDEA and most IntelliJ-based IDEs).
