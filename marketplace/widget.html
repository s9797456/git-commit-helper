Official JetBrains Marketplace widgets for plugin 34303.

These widgets are browser scripts, so they only render on a real web page. GitHub strips <script> from Markdown, which is why README.md uses the shields.io badges instead. Host this file anywhere (GitHub Pages, an internal site, a docs site) to show the widgets.

The snippets this page runs

<script src="https://plugins.jetbrains.com/assets/scripts/mp-widget.js"></script>
<script>
  MarketplaceWidget.setupMarketplaceWidget('card', 34303, "#mp-card");
  MarketplaceWidget.setupMarketplaceWidget('install', 34303, "#mp-install");
</script>

The third argument is a CSS selector for the element the widget renders into — it is the #yourelement placeholder from the snippet JetBrains gives you.
